Doubly Robust Methods (DML)

The conceptual spine — why AIPW + cross-fitting is the estimator the whole inference library is built around.

AIPW combines a regression guess and an IPW reweighting so an error in either one is forgiven — and with cross-fitting it reaches the best variance any estimator can achieve, using arbitrary ML nuisances.

1The setting

Observe \((X_i,W_i,Y_i)\), want \(\tau=E[Y_i(1)-Y_i(0)]\). Three assumptions: SUTVA \(Y_i=Y_i(W_i)\); unconfoundedness \(\{Y_i(0),Y_i(1)\}\perp\!\!\!\perp W_i\mid X_i\); strong overlap \(\eta\le e(x)\le 1-\eta\), with propensity \(e(x)=P(W{=}1\mid X{=}x)\) and response surfaces \(\mu_{(w)}(x)=E[Y\mid X{=}x,W{=}w]\).

2Two views of the same ATE

View A — IPW (model the propensity)
$$\hat\tau_{IPW}=\frac1n\sum_i\Big[\frac{W_iY_i}{e(X_i)}-\frac{(1-W_i)Y_i}{1-e(X_i)}\Big]$$
View B — regression (model the outcome)
$$\hat\tau_{REG}=\frac1n\sum_i\big(\hat\mu_{(1)}(X_i)-\hat\mu_{(0)}(X_i)\big)$$
💡 Intuition IPW reweights the data we have to look randomized; regression imputes the data we don't have. Each leans on a different model — so use both.

3AIPW — combine them

Start from the regression guess; use IPW on the residuals to mop up what it got wrong:

$$\hat\tau_{AIPW}=\frac1n\sum_i\Big[\underbrace{\green{\hat\mu_{(1)}(X_i)}-\green{\hat\mu_{(0)}(X_i)}}_{\text{outcome model}}+\underbrace{W_i\tfrac{Y_i-\green{\hat\mu_{(1)}(X_i)}}{\pink{e(X_i)}}-(1-W_i)\tfrac{Y_i-\green{\hat\mu_{(0)}(X_i)}}{\pink{1-e(X_i)}}}_{\text{IPW correction}}\Big]$$

● outcome model \(\hat\mu\)   ● propensity \(e\) (the two nuisances)

The per-unit summand is the AIPW / doubly-robust / influence-function score \(\Gamma_i\) — the same object that returns in policy & off-policy evaluation (ch.5).

4Weak double robustness

Consistent if either \(\hat\mu\) or \(\hat e\) is right.

💡 Why If \(\hat\mu\) is right, residuals are mean-zero so the (wrong) weights multiply noise and wash out. If \(\hat e\) is right, IPW is already unbiased and the (wrong) regression terms cancel. Two nets, need one.
⚠️ Don't oversell Weak DR only buys consistency. With flexible ML both nuisances are consistent anyway — so "either/or" adds nothing. The result that matters is the strong one.

5Strong DR & cross-fitting

AIPW's bias is the product of the nuisance rates, \(n^{-(\alpha_\mu+\alpha_e)}\). So as long as

$$\alpha_\mu+\alpha_e\ge\tfrac12\quad(\text{e.g. both }n^{-1/4})\ \Longrightarrow\ \sqrt n(\hat\tau_{AIPW}-\tau)\Rightarrow N(0,V^*)$$
💡 The magic Regression alone has bias \(n^{-\alpha_\mu}\), IPW alone \(n^{-\alpha_e}\); AIPW gets their product — far smaller. So slow ML (forests, boosting, nets), each only beating \(n^{-1/4}\), still gives \(\sqrt n\)-valid inference on \(\tau\).

Cross-fitting: fit \(\hat\mu,\hat e\) on the other \(K{-}1\) folds, evaluate residuals out-of-fold → "honest" residuals overfitting can't shrink. AIPW + cross-fitting = double/debiased ML (DML), Chernozhukov et al. 2018.

Why orthogonality is the real reasonThe AIPW score is Neyman-orthogonal: \(\partial_\eta E[\psi]=0\) at the truth, so first-order nuisance errors don't move the estimate; cross-fitting kills the second-order own-fold bias. Together → the \(\alpha_\mu+\alpha_e\ge\frac12\) condition. Full: notation/dml.md.

6Efficiency & CIs

\(V^*\) is the semiparametric efficiency bound — no estimator under these assumptions beats it:

$$V^*=\mathrm{Var}[\tau(X_i)]+E\Big[\tfrac{\sigma^2_{(1)}(X_i)}{e(X_i)}\Big]+E\Big[\tfrac{\sigma^2_{(0)}(X_i)}{1-e(X_i)}\Big]$$
$$\hat V_{AIPW}=\tfrac1{n-1}\sum_i(\hat\Gamma_i-\hat\tau)^2,\qquad \hat\tau_{AIPW}\pm\Phi^{-1}(1-\tfrac\alpha2)\sqrt{\hat V_{AIPW}/n}$$

7Vega's shortcut & what it feeds

🎯 Vega hook — Corollary 3.3 When \(e(x)\) is known, AIPW hits \(V^*\) with any consistent \(\hat\mu\) — no rate condition. Vega's engine sets \(e(x)\), so recovery tests can assert efficient, \(\sqrt n\)-valid coverage cleanly. The single most useful fact here.

8The DML algorithm, step by step

From your notes — the partially-linear model with target \(\blue{\alpha}\), controls \(x\), treatment \(d\), outcome \(y\) (here \(d=W,\ x=X\)):

$$y_i=\blue{\alpha_0}\, d_i+\green{g_0(x_i)}+\varepsilon_i,\qquad d_i=\pink{m_0(x_i)}+u_i$$

● target \(\alpha\)   ● outcome model \(g,\beta,\hat\varepsilon\)   ● treatment model \(m,\gamma,\hat u\)   ● \(y\)-residual \(\hat v\)   ● raw \(d\)   ● prelim \(\tilde\alpha\)

(a) Partialling-out (Robinson) score — \(k=2\) folds \(S_1,S_2\):

  • Step 0 — partition into folds \(S_1,S_2\) (size \(n/k\)).
  • Step 1 — on \(S_1\) regress \(y\) on \(x\) (Lasso/Post-Lasso); residualize out-of-fold on \(S_2\): $$\purple{\hat v_{i2}}=y_{i2}-x_{i2}'\purple{\hat\theta_1}$$
  • Step 2 — on \(S_1\) regress \(d\) on \(x\); residualize: $$\pink{\hat u_{i2}}=d_{i2}-x_{i2}'\pink{\hat\gamma_1}$$
  • Step 3 — regress \(\hat v\) on \(\hat u\): $$\blue{\hat\alpha_2}=\Big[\tfrac1n\textstyle\sum_i \pink{\hat u_{i2}^2}\Big]^{-1}\Big[\tfrac1n\textstyle\sum_i \pink{\hat u_{i2}}\,\purple{\hat v_{i2}}\Big]$$
  • Steps 4–6 — swap folds (fit on \(S_2\), residualize on \(S_1\)) → \(\blue{\hat\alpha_1}\).
  • Step 7 — aggregate (DML1 / DML2 below).
💡 (b) IV-type score — the variation Same idea, two steps differ: Step 1 regresses \(y\) on \(x\) without penalizing \(d\), giving \(\green{\hat g}\) and \(\green{\hat\varepsilon_{i2}}=y_{i2}-\gray{\tilde\alpha}\,d_{i2}-x_{i2}'\green{\hat\beta_1}\); Step 3 regresses \(\hat\varepsilon\) on \(d\) using \(\hat u\) as an instrument: $$\blue{\hat\alpha_2}=\Big[\tfrac1n\textstyle\sum_i \pink{\hat u_{i2}}\,\orange{d_{i2}}\Big]^{-1}\Big[\tfrac1n\textstyle\sum_i \pink{\hat u_{i2}}\,\green{\hat\varepsilon_{i2}}\Big]$$ doubleml exposes these as score="partialling out" vs "IV-type"; nuisances can be Lasso, random forest, etc.
See it as 2SLS (your notes, verbatim) $$\text{1st stage: }\orange{d_{i2}}=\phi_{02}\,\pink{\hat u_{i2}}+e_{i2}\qquad \text{2nd stage: }\underbrace{[\,y_{i2}-\gray{\tilde\alpha}\, d_{i2}-x_{i2}'\green{\hat\beta_1}\,]}_{\green{\hat\varepsilon_{i2}}}=\blue{\hat\alpha_2}\,\orange{\hat d_{i2}}+e_{i2}$$ i.e. the IV-type score is 2SLS with the treatment residual \(\pink{\hat u}\) as the instrument for \(\orange{d}\).

DML1 vs DML2 — how to aggregate across folds:

$$\textbf{DML1:}\ \ \blue{\hat\alpha_{\rm DML}}=\frac1k\sum_{k}\blue{\hat\alpha_k}\qquad\text{(solve each fold, then average)}$$
$$\textbf{DML2:}\ \ \blue{\hat\alpha_{\rm DML}}=\Big[\tfrac1n\sum_{k}\sum_i \pink{\hat u_{ik}^2}\Big]^{-1}\Big[\tfrac1n\sum_{k}\sum_i \pink{\hat u_{ik}}\,\purple{\hat v_{ik}}\Big]\quad\text{(pool moments, solve once)}$$

DML2 pools the empirical moment across folds before solving — usually more stable, and the doubleml default.

9Double Selection (the pre-ML ancestor)

Belloni–Chernozhukov–Hansen 2014 — estimate \(\alpha\) in \(y=d\,\alpha+x'\beta+\varepsilon\) with high-dimensional controls \(x\):

  • Step 1 — Lasso regress \(y\) on \(x\); keep controls \(\hat I_1\) that predict the outcome.
  • Step 2 — Lasso regress \(d\) on \(x\); keep controls \(\hat I_2\) that predict the treatment.
  • Step 3 — OLS of \(y\) on \(d\) and the union \(\hat I_1\cup\hat I_2\); the coefficient on \(d\) is \(\color[HTML]{C79A3A}{\hat\alpha}\).
⚠️ Why the union (OMV) Single selection (Step 1 only) can drop a control that weakly predicts \(y\) but strongly predicts \(d\) — a confounder → omitted-variable bias. Selecting controls that predict either closes the gap → uniformly valid inference under approximate sparsity. Same intuition as partialling-out: residualize \(y\) and \(d\) on \(x\).

10The estimator family & the two biases

Naive ML plug-in carries two biases; the orthogonal score and cross-fitting kill one each:

BiasSourceFix
Regularizationfirst-order in the ML bias of \(\hat g\) (\(\sqrt n\cdot n^{-\alpha}\to\infty\))Neyman orthogonality → bias becomes the product of nuisance errors (\(\alpha_g+\alpha_m\ge\tfrac12\))
Overfittingnuisance fit correlates with its own-fold residualCross-fitting → evaluate the moment out-of-fold

The orthogonal score turns the leading bias into the product of the two nuisance errors (your notes, verbatim):

$$b=(\text{E}[V_i^2])^{-1}\tfrac1{\sqrt n}\sum_i \underbrace{\pink{[\hat m_0(X_i)-m_0(X_i)]}}_{\text{treatment-model error}}\times\underbrace{\green{[\hat g_0(X_i)-g_0(X_i)]}}_{\text{outcome-model error}}$$

→ vanishes once \(\alpha_g+\alpha_m\ge\tfrac12\) (e.g. both \(n^{-1/4}\)); the naive score instead has \(b\propto\sum_i m_0[g_0-\hat g_0]\to\infty\).

…and the lineage of estimators these two ideas produce:

Heterogeneous Effects — CATE, metalearners & causal forests

From "what's the average effect" to "who responds" — the engine behind Game B targeting and the eval funnel.

Target the CATE \(\tau(x)=E[Y(1)-Y(0)\mid X{=}x]\) (point-identified; the ITE is not). Metalearners and causal forests are all the same orthogonal moment in different clothes.

1The CATE & why naive fails

The unrestricted optimal targeting rule thresholds the CATE: \(\pi^*(x)=\mathbb 1\{\tau(x)>0\}\) (ch.5). The obvious estimator — fit \(\hat\mu_0,\hat\mu_1\) separately and subtract (the T-learner) — suffers regularization-induced confounding:

⚠️ The trap When arms are unbalanced or differently complex, \(\hat\mu_0,\hat\mu_1\) are regularized differently, and their difference invents heterogeneity that isn't there. Don't target \(\tau\) by differencing two separately-tuned models.

2Metalearners (S / T / X)

LearnerRecipeBest when
Singleone model \(\hat\mu(x,w)\) with \(w\) as a feature; \(\hat\tau_S=\hat\mu(x,1)-\hat\mu(x,0)\)effect small / possibly zero (shrinks toward 0)
Two\(\hat\tau_T=\hat\mu_{(1)}-\hat\mu_{(0)}\)effects large, arms balanced, data-rich
X (Künzel)impute ITEs vs other arm, regress, combineunbalanced arms — e.g. Vega's low-treated-share ramp
X-learner (Künzel et al. 2019)
$$\tilde D_i^{1}=Y_i-\hat\mu_{(0)}(X_i)\ (\text{treated}),\quad \tilde D_i^{0}=\hat\mu_{(1)}(X_i)-Y_i\ (\text{control}),\quad \hat\tau_X(x)=g(x)\hat\tau_0(x)+(1-g(x))\hat\tau_1(x)$$
💡 Why X helps It imputes each unit's effect using the other arm's (well-estimated) model, then down-weights the estimate from the smaller arm via \(g(x)\) (often \(\hat e\)). Provably adapts to CATE sparsity/smoothness and shines when one arm dwarfs the other.

3R-learner & DR-learner (the orthogonal ones)

R-learner (Nie–Wager) = Robinson residual-on-residual with the R-loss:

$$\hat\tau=\arg\min_\tau\frac1n\sum_i\big(\purple{(Y_i-\hat\ell^{(-k)}(X_i))}-\pink{(W_i-\hat e^{(-k)}(X_i))}\,\blue{\tau(X_i)}\big)^2+\Lambda(\tau)$$

Exactly the DML partialling-out colours (ch.3 §8): ● \(y\)-residual · ● treatment-residual · ● target — because the R-learner is partialling-out with a featurized treatment.

DR-learner (Kennedy) = regress the AIPW score \(\hat\Gamma_i\) (from ch.3) on \(X\). Both are Neyman-orthogonal — the principled defaults with ML nuisances.

4Causal forests / GRF

A random forest is an adaptive kernel: \(\hat\mu(x)=\sum_i\alpha_i(x)Y_i\), where \(\alpha_i(x)\) = how often \(i\) shares a leaf with \(x\). GRF reuses those weights to solve a local centered (R-learner) moment:

$$\hat\tau(x)=\frac{\sum_i\alpha_i(x)\,\pink{(W_i-\hat e(X_i))}\,\purple{(Y_i-\hat\ell(X_i))}}{\sum_i\alpha_i(x)\,\pink{(W_i-\hat e(X_i))}^2}$$
💡 One mental model A causal forest is just the R-learner with forest weights. Metalearners, the R-learner, GRF, and DML are not four ideas — they're four instantiations of the same orthogonal moment. Honesty (split-sample within each tree) + subsampling give pointwise CIs (Wager–Athey 2018).

The useful grf readouts: average_treatment_effect (DR ATE+CI), best_linear_projection (which features drive heterogeneity), and rank_average_treatment_effect → RATE/AUTOC — a formal test that predicted uplift actually ranks units by realized effect.

5What it feeds in Vega

🎯 Vega hook RATE/AUTOC is the Game-B eval metric: does the ranker's predicted uplift rank users by their true effect? And W.hat = 0.5 (known propensity — the engine sets it) removes propensity-estimation error, same cheat code as DR Cor 3.3. Use econml (SLearner…XLearner, DRLearner, CausalForestDML) / causalml — don't hand-roll.

Policy Learning & Off-Policy Evaluation

From estimating \(\tau(x)\) to deciding who to treat — and the doubly-robust policy value that is the OPE leg.

The AIPW policy value is exactly the doubly-robust off-policy evaluation estimator Vega's ranking leg needs; the policy comparison is the ship-decision number.

1Policy value & OPE

Policy \(\pi:\mathcal X\to\{0,1\}\), value \(V(\pi)=E[Y_i(\pi(X_i))]\). The doubly-robust (AIPW) estimate is the OPE workhorse:

$$\hat V_{AIPW}(\pi)=\frac1n\sum_i\Big[\hat\mu_{\pi(X_i)}(X_i)+\frac{\mathbb 1\{W_i=\pi(X_i)\}}{P(W_i=\pi(X_i)\mid X_i)}\big(Y_i-\hat\mu_{\pi(X_i)}(X_i)\big)\Big]$$

2Policy comparison = ship decision

$$\hat\Delta_{AIPW}(\pi_1,\pi_2)=\frac1n\sum_i(\pi_1(X_i)-\pi_2(X_i))\,\hat\Gamma_i$$
💡 Why it's precise Only units where \(\pi_1,\pi_2\) disagree contribute — so comparing a new ranker to the status quo needs far less data than estimating each value. \(\Delta(\pi,\mathbf 0)\) = the policy's benefit; \(\Delta(\mathbf 1)=\) ATE.

3QINI / TOC — uplift evaluation

Priority \(S(x)\), treat top-\(q\): QINI plots benefit \(\Delta(\pi_S^q)\) vs \(q\) (cost-benefit of spending more); TOC plots \(q^{-1}\Delta(\pi_S^q)-\Delta(\mathbf 1)\) (do the top-\(q\) beat random?). AUC-TOC with \(S=\hat\tau\) ↔ the RATE/AUTOC from ch.4.

4Empirical-welfare maximization

Learn over a restricted class \(\Pi\): \(\hat\pi=\arg\max_{\pi\in\Pi}\hat V(\pi)\). Regret \(\sqrt n\,E[R(\hat\pi)]\lesssim\sqrt{\mathrm{VC}(\Pi)V^*}\). Equivalent to weighted classification: label = \(\mathrm{sign}(\hat\Gamma_i)\), weight = \(|\hat\Gamma_i|\).

⚠️ Two cautions (1) Don't swap in a logistic/hinge surrogate — the guarantees break. (2) Restrict the deploy class \(\Pi\): gameable / protected / hard-to-measure features stay in \(\hat\mu,\hat e\) but out of \(\pi\).
🎯 Vega hook \(\hat V_{AIPW}(\pi)\) is inference/ope.py — score a counterfactual ranker from logs, validate vs the engine's known policy value. \(\hat\Delta(\hat\pi,\pi_0)\) = the Game-B ship-decision banner; QINI/TOC = the uplift readout.

Spillovers & Interference

When one unit's treatment moves another's outcome — the heart of why naive A/B is biased in a marketplace, and how to fix it.

SUTVA fails ⇒ up to \(2^n\) potential outcomes \(Y_i(\mathbf w)\). Tame it with exposure mappings; do randomization-only inference; and discover that clustering recovers cluster-robust SEs.

1Exposure mappings — taming \(2^n\)

An exposure mapping \(H_i(\mathbf w)\) summarizes how the whole assignment hits \(i\): \(Y_i(\mathbf w)=Y_i(\mathbf w')\) when \(H_i(\mathbf w)=H_i(\mathbf w')\). Test which one you need via a nested ladder (closed testing ⇒ no multiplicity):

Cluster interference \(H_i=(w_j)_{j\in C_i}\): no cross-cluster spillover ⇒ SUTVA at the cluster level ⇒ cluster-randomize and analyze normally.

🎯 Vega hook The ride-sharing example is Vega's archetype: give all drivers incentives and per-trip pay rises, but more drivers log on, idle time grows, and the hourly gain cancels — spillover via market re-equilibration. Budget cannibalization & shared attention are the same thing.

2Estimating exposure effects (IPW / Horvitz–Thompson)

Exposure effect \(\bar\tau(h,h')=\frac1n\sum_i(Y_i(h')-Y_i(h))\). With exposure propensity \(e_i(h)=P(H_i(\mathbf W)=h)\), HT/IPW is unbiased for free:

$$\hat\tau_{IPW}(h,h')=\frac1n\sum_i\Big[\frac{\mathbb 1\{H_i=h'\}Y_i}{e_i(h')}-\frac{\mathbb 1\{H_i=h\}Y_i}{e_i(h)}\Big],\qquad E_W[\hat\tau_{IPW}]=\bar\tau(h,h')$$

3Finite-population variance → cluster-robust SEs

No superpopulation; potential outcomes fixed, randomness only from \(\mathbf W\) (Neyman). The true variance isn't identified, but the IID variance estimate is a conservative bound. With dependency graph \(G_{ij}=\mathbb 1\{(\{i\}\cup N_i)\cap(\{j\}\cup N_j)\neq\varnothing\}\), the HAC variance is

$$\hat\sigma^2(h,h')=\tfrac1n(\Gamma(h')\odot\mathbf Y-\Gamma(h)\odot\mathbf Y)^\top G\,(\Gamma(h')\odot\mathbf Y-\Gamma(h)\odot\mathbf Y)$$
🎯 Vega hook — the cluster justification When \(G\) is block/cluster-diagonal, this HAC variance is exactly the cluster-robust estimator. So cluster-robust SEs aren't an IID convenience — they're the finite-population-correct thing under randomization alone. That's the citation behind inference/cluster.py (and ties to Hansen 2025's jackknife).

4Direct / indirect effects & the marketplace

$$\tau_{ADE}=\tfrac1n\sum_iE_W[Y_i(1,\mathbf W_{-i})-Y_i(0,\mathbf W_{-i})],\quad \tau_{AIE}=\tfrac1n\sum_i\sum_{j\neq i}E_W[Y_j(W_i{=}1,\mathbf W_{-i})-Y_j(W_i{=}0,\mathbf W_{-i})]$$
💡 Closest to Vega Munro–Kuang–Wager 2025 derive these under marketplace equilibrium interference (prices align supply & demand) with spillover-aware CATE targeting — essentially the Vega DGP. Acquire it (INDEX §02).

RCTs & Inverse-Propensity Weighting

The foundation: how randomization identifies effects, and the first move beyond it — unconfoundedness + the propensity score.

Difference-in-means is unbiased almost for free; regression adjustment is a free variance cut (= CUPED); and once treatment isn't randomized, the propensity \(\pink{e(x)}\) carries everything.

📋 Assumptions (the standard trio) 1. SUTVA — \(Y_i=Y_i(W_i)\) (no interference; one version of treatment).   2. Unconfoundedness (Rosenbaum–Rubin 1983) — \(W_i\perp\!\!\!\perp(Y_i(0),Y_i(1))\mid X_i\).   3. Overlap / positivity — \(\eta\le \pink{e(x)}\le 1-\eta\).
In an RCT, unconfoundedness holds by design with \(\pink{e(x)}=\pi\) known. Regression-with-controls quietly adds two more (constant effects + linearity — §6).

1Estimand & SUTVA

Potential outcomes \(Y_i(0),Y_i(1)\), with \(Y_i=Y_i(W_i)\) (SUTVA). Target: the ATE \(\tau=E[Y_i(1)-Y_i(0)]\). The individual effect \(\Delta_i=Y_i(1)-Y_i(0)\) is never observed — only one arm per unit.

2Difference-in-means → naive.py

$$\hat\tau_{DM}=\frac1{n_1}\sum_{W_i=1}Y_i-\frac1{n_0}\sum_{W_i=0}Y_i,\qquad \sqrt n(\hat\tau_{DM}-\tau)\Rightarrow N(0,V_{DM}),\ \ V_{DM}=\tfrac{\mathrm{Var}[Y(1)]}{\pi}+\tfrac{\mathrm{Var}[Y(0)]}{1-\pi}$$

Unbiased under randomization essentially without assumptions. CI: \(\hat\tau_{DM}\pm\Phi^{-1}(1-\tfrac\alpha2)\sqrt{\hat V_{DM}/n}\). This is Vega's biased-under-interference baseline.

3Regression adjustment = CUPED → cuped.py

Fit the interacted regression \(Y\sim\alpha+W\tau+X\beta+WX\gamma\); report \(\hat\tau_{IREG}=\hat\tau+\bar X\hat\gamma\).

💡 A free lunch The interacted regression is never worse than diff-in-means asymptotically — \(V_{IREG}=V_{DM}-\lVert\beta_{(0)}^*+\beta_{(1)}^*\rVert_A^2\le V_{DM}\) — even if the linear model is misspecified. Exactly the CUPED variance-reduction logic.

4Unconfoundedness & the propensity score

Drop randomization, assume \(\{Y(0),Y(1)\}\perp\!\!\!\perp W\mid X\). The propensity \(\pink{e(x)}=P(W{=}1\mid X{=}x)\) is a balancing score:

$$\{Y(0),Y(1)\}\perp\!\!\!\perp W\mid \pink{e(X)}\qquad(\text{conditioning on }\pink{e(X)}\text{ suffices, not all of }X)$$
⚠️ Not "add X to a regression" Under unconfoundedness, throwing \(X\) into \(Y\sim\alpha+W\tau+X\beta\) is not consistent for the ATE — you must adjust non-parametrically (stratify / IPW / AIPW).

5IPW, stratification & overlap

$$\hat\tau_{IPW}=\frac1n\sum_i\Big[\frac{W_iY_i}{\pink{e(X_i)}}-\frac{(1-W_i)Y_i}{\pink{1-e(X_i)}}\Big]$$

Stratification (discrete \(X\)): \(\hat\tau_{STRAT}=\sum_x\tfrac{n_x}{n}\hat\tau(x)\) — its variance doesn't grow with the number of strata. Oracle IPW is unbiased but inefficient; the fix is AIPW (→ ch.3). Overlap \(\eta\le \pink{e(x)}\le 1-\eta\) is load-bearing — if \(W\) is perfectly predictable from \(X\), no effect is identified.

🎯 Vega hook The engine sets \(\pink{e(x)}\), so overlap holds by construction and the propensity is known — recovery tests get clean coverage (and AIPW needs no nuisance-rate condition, ch.3 Cor 3.3). Cluster-level stratification → inference/cluster.py.

6Regression with rich controls — the linearity tax

The econometrician's reflex is to "control for \(X\)" by running \(Y_i=\alpha+\tau W_i+\beta'X_i+\varepsilon_i\). But this is not justified by unconfoundedness alone (Wager ch.2) — it silently adds two assumptions (Imbens–Wooldridge 2009):

  1. Constant treatment effects \(\tau=Y_i(1)-Y_i(0)\) (no heterogeneity), and
  2. Linearity of \(\mu_{(0)}(x)=E[Y(0)\mid X{=}x]=\alpha+\beta'x\).

Given both, unconfoundedness \(\Leftrightarrow \varepsilon_i\perp\!\!\!\perp W_i\mid X_i\) and OLS \(\hat\tau\) is the ATE. The non-parametric imputation estimator needs neither:

$$\hat\tau_{reg}=\frac1N\sum_i\big(\green{\hat\mu_{(1)}(X_i)}-\green{\hat\mu_{(0)}(X_i)}\big)\ \xrightarrow{\ \text{linear arms}\ }\ \hat\alpha_1-\hat\alpha_0\ \ (=\text{coef on }W\text{ in the interacted regression, §3})$$
⚠️ The OLS-weighting trap (Angrist) With discrete \(X\), plain-control OLS and IPW are both weighted averages of group effects \(\tau_x\) — but with different weights: $$\tau^{IPW}=\frac{\sum_x\tau_x\,\pink{e(x)}\,P(X{=}x)}{\sum_x \pink{e(x)}\,P(X{=}x)},\qquad \tau^{OLS}=\frac{\sum_x\tau_x\,\pink{\sigma^2_{W|x}}\,P(X{=}x)}{\sum_x \pink{\sigma^2_{W|x}}\,P(X{=}x)},\quad \pink{\sigma^2_{W|x}}=e(x)(1-e(x))$$ OLS weights by the conditional variance of treatment \(\pink{\sigma^2_{W|x}}\) — maximal at \(e(x)=\tfrac12\) — so it over-weights 50/50-split strata and under-weights imbalanced ones, equalling the ATE only if effects are constant (\(\tau_x\equiv\tau\)). IPW weights by treatment probability and targets the ATE directly.

Bottom line: regression can be severely biased if the linear model is wrong globally (Imbens–Wooldridge) — the field moved to matching / weighting / doubly-robust. This is the "linearity tax" the AIPW/DML machinery (ch.3) removes.

Instrumental Variables & LATE

When treatment is endogenous, a randomized nudge identifies the effect — for the compliers. The frame behind ghost-ads incrementality.

The IV (Wald) ratio recovers the average effect among the units the instrument actually moves — the compliers. Ghost-ads/holdout is exactly this: the reward nudges engagement.

1Setup & the four assumptions

Instrument \(\orange{Z}\), treatment received \(W\) (endogenous), outcome \(Y\); \(W_i=W_i(\orange{Z_i})\).

  • Exclusion — \(\orange{Z}\) affects \(Y\) only through \(W\).
  • Exogeneity — \(\orange{Z}\) is randomized (independent of potential outcomes).
  • Relevance — \(\orange{Z}\) moves \(W\): \(E[W_i(1)-W_i(0)]\neq0\).
  • Monotonicity — no defiers.

2The Wald estimand

$$\hat\tau_{IV}=\frac{\widehat{\mathrm{Cov}}[Y,\orange{Z}]}{\widehat{\mathrm{Cov}}[W,\orange{Z}]}=\frac{E[Y\mid \orange{Z}{=}1]-E[Y\mid \orange{Z}{=}0]}{E[W\mid \orange{Z}{=}1]-E[W\mid \orange{Z}{=}0]}$$

The reduced-form (ITT) divided by the first-stage take-up.

3LATE = the compliers' effect

$$\tau_{IV}=E\big[Y_i(1)-Y_i(0)\mid C_i=\text{complier}\big]$$
\(W(1)=0\)\(W(1)=1\)
\(W(0)=0\)never-takercomplier
\(W(0)=1\)defier (ruled out)always-taker

Practical: raw diff-in-means \(\div\) first-stage take-up = LATE (Oregon Medicaid: ÷ 0.3). Different instruments → different complier sets → different LATEs (don't naively pool without linearity).

4Supply–demand IV & the MTE

With an instrument that shifts supply but not demand, IV recovers a positive-weighted average of demand slopes over the price range the instrument moves — the elasticity story. The marginal treatment effect \(\tau(u)\) generalizes LATE via local IV: \(\tau(c(z))=\tfrac{d/dz\,E[Y\mid Z=z]}{d/dz\,P(W{=}1\mid Z=z)}\).

🎯 Vega hook Ghost-ads / holdout = an encouragement (IV) design. The reward \(\orange{Z}\) nudges engagement \(W\); the lift on advertiser conversions among responders is a LATE — that's inference/incrementality.py, validated against the engine's known effect. The same IV logic anchors reward-elasticity calibration.

Difference-in-Differences & Event Studies

Panel data, off→on adoption, parallel trends — and the staggered-adoption trap that quietly breaks two-way fixed effects.

DiD identifies the ATT under parallel trends; but the familiar TWFE regression is biased under staggered adoption — use imputation/ASR or cohort-wise estimators.

1Panel setup & assumptions

\(Y_{it},\ W_{it}\in\{0,1\}\), treatment only switches off→on. Block adoption: shared event time \(H\). Staggered: unit-specific start \(H_i\). Assumes non-anticipation (\(Y_{it}(0)=Y_{it}(1)\) for \(t\le H\)) and parallel trends (untreated potential outcomes evolve in parallel).

2The DiD estimator

$$\hat\tau_{DID}=\big[\bar Y^{\text{post}}_{D=1}-\bar Y^{\text{pre}}_{D=1}\big]-\big[\bar Y^{\text{post}}_{D=0}-\bar Y^{\text{pre}}_{D=0}\big]$$
💡 Two justifications DiD is unbiased under randomized adoption or under parallel trends — a double-robustness-style property for the same estimator.

3The TWFE staggered trap

$$Y_{it}\sim\alpha_i+\beta_t+W_{it}\tau$$
⚠️ Negative weights TWFE equals DiD under block adoption — but under staggered adoption \(\hat\tau\) is biased: implied weights \(\gamma_{it}\) can be negative for already-treated units used as controls ("forbidden comparisons"). It can converge negative even if every effect is positive.

4The fix & synthetic control

Averaged saturated regression / imputation (Borusyak–Jaravel–Spiess; Wooldridge): saturate \(Y_{it}\sim\alpha_i+\beta_t+W_{it}\theta_{it}\), then average \(\hat\theta_{it}\) over treated cells. Or cohort-wise estimators (Callaway–Sant'Anna, Sun–Abraham). When parallel trends fails, SDID reweights controls to restore it.
